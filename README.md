
# Neura AI - Artificial Intelligence Website 🤖

## About the Project
Neura AI is a modern and responsive website that introduces
Artificial Intelligence and its real-world applications.

It explores AI technologies, innovations and future possibilities.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Futuristic AI landing page
- Animated AI visual
- About Artificial Intelligence section
- AI Technology cards
- Real-world AI applications
- Future of AI section
- Contact section
- Interactive navigation
- Responsive design

## Project Structure
- index.html
- style.css
- script.js
- README.md
- screenshots/

## How to Run
1. Download or clone the repository.
2. Open the folder in VS Code.
3. Open index.html using Live Server.
